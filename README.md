# Flyback Transformer Designer

**Программа предварительного расчёта многообмоточных обратноходовых трансформаторов** / open-source multi-winding flyback transformer design tool.

**Status: experimental v0.1 (DCM only).** The repository contains independent calculations; executable files from proprietary transformer design packages are not redistributed.


## Универсальный режим и инженерные рекомендации (v0.2 draft)

**Программа не привязана к UCC21750, ETD39 или конкретному блоку питания.**
Проект содержит произвольное число вторичных обмоток и именованных
изолированных групп. По умолчанию открывается нейтральный пример
с выходами +12 В, −12 В и +5 В; отдельный файл с драйверами IGBT
оставлен исключительно как пример.

В основном окне есть три рабочие вкладки: **Результаты**,
**Диагностика и рекомендации**, **Укладка на каркасе**.
Обмотки можно добавлять, копировать, удалять, менять местами и выбирать
опорную. Есть каталог сердечников и ручной ввод Ae, Aw, le, μr, MLT.

Геометрический режим принимает ширину намотки, MLT, доступную радиальную
толщину, поля и ленты. Считает количество слоёв, толщину намотки и
приблизительную длину провода. Если радиальный размер неизвестен,
результат остаётся **непроверенным**. Толщина лент не подтверждает
электрическую прочность и не заменяет проверку изоляции.

Все параметры каркаса сохраняются вместе с проектом JSON.
Большой демонстрационный проект — examples/generic_24_windings.json.

Проверка с рекомендациями из консоли:

    python app.py --cli examples/generic_24_windings.json --advice

**Ограничение текущей версии:** универсальный инструмент для Flyback
в режиме DCM. Поддержка CCM, Forward, Push-Pull, Half/Full Bridge
потребует отдельных физических моделей. Тепловой режим,
перекрёстная стабилизация, защита изоляции, клампер и EMI пока
не рассчитаны. Советы не заменяют реальные испытания.

## Возможности

- Произвольное количество вторичных обмоток и изолированных групп
- Положительные и отрицательные напряжения относительно условного COM группы
- Предварительный подбор первичных и вторичных витков, Lp, AL и магнитного зазора
- Ограничения по Bpk, длительности размагничивания и заполнению окна
- Подбор параллельных проводников и приближённые потери меди по DC-сопротивлению
- Сравнение геометрии ETD29, ETD34, ETD39, ETD44, ETD49 и E-Sh5x5
- GUI Windows/Linux (Python + Tkinter), CLI, сохранение JSON, экспорт TXT
- Пример на восемь вторичных обмоток для четырёх изолированных групп UCC21750

## Установка и запуск

Необходим Python **3.10+** с Tkinter; сторонние библиотеки Python не нужны.

**Windows:** скачайте ZIP репозитория или выполните clone, затем дважды запустите `run_windows.bat`. Если Python не установлен, установите его с python.org и включите Add Python to PATH.

**Linux:**
```bash
python3 app.py
```

**Расчёт без GUI:**
```bash
python app.py --demo
python app.py --cli examples/ucc21750_4_domains.json --out report.txt
python app.py --compare-cores
python -m unittest discover -s tests -v
```

В GUI редактируются параметры питания и сердечника. Для каждой обмотки указываются группа, название, напряжение **до стабилизатора**, ток и падение на диоде. Первая строка в таблице определяет опорное отношение витков. Кнопка «Сделать опорной» меняет опорную обмотку.

## Пример 4×(+18 В/−11 В)

В `examples/ucc21750_4_domains.json` приведены четыре отдельные группы: Upper A/B/C и Lower. Каждая имеет вторичные обмотки с условными напряжениями +18 В и −11 В **до LM317/LM337**, предназначенные для получения +15 В и −8 В после стабилизации.

Демонстрационные токи +18 В @ 80 мА и −11 В @ 30 мА **не являются подтверждёнными нагрузками UCC21750**. Необходимо заменить их измеренными или рассчитанными значениями с учётом частоты переключения, заряда затвора и других потребителей.

## Что рассчитывается

Расчёт ведётся в допущении идеального DCM при `Vin_min` и заданной нагрузке.

- `P_in = P_out / eta`
- `P_in = 0.5 * Lp * Ipk² * f`
- `Ipk = 2*P_in/(Vin_min*D)`
- `Bpk = Lp*Ipk/(Np*Ae)`
- `AL = Lp/Np²`
- `D_demag ≈ Vin_min*D/Vref`

Целочисленные варианты витков фильтруются по допустимой индукции, зазору, свободному периоду для размагничивания и приблизительному заполнению окна.

## Критические ограничения

Это **не программа для окончательного инженерного проектирования** и не сертифицированный расчёт изоляции. Отсутствуют:

1. Проверенные кривые потерь конкретных ферритов (N87/N95 и др.), температура сердечника, fringing и AC/proximity потери меди.
2. Строгая модель распределения энергии и кросс-регулирования между несколькими вторичными обмотками.
3. Укладка реальных слоёв, габариты каркаса, изоляционные ленты, пути утечки и воздушные зазоры.
4. Расчёт выбросов на MOSFET, индуктивности рассеяния, RCD/TVS клампера, EMI, запуска и переходных режимов.
5. CCM/BCM, точная работа UC3843 на всех нагрузках и ограничение максимального тока при повышении входного напряжения.

Параметры каталога сердечников приблизительные и должны проверяться по официальным datasheet производителя, особенно `Aw`, `MLT` и магнитная проницаемость. Расчётный полный магнитный зазор не равен гарантированной толщине прокладки.

**Не использовать результаты напрямую для высоковольтных IGBT-драйверов или сетевых блоков питания.** Перед применением необходимы проверка конструкции и изоляции, измерения Lp/AL, осциллограммы тока, тепловые испытания и соответствие применимым требованиям безопасности.
