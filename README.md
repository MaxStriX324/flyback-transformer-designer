# Flyback Transformer Designer

Open-source engineering tool for preliminary design and optimization of multi-winding flyback transformers.

> **Status:** early prototype. Calculations are preliminary and not validated for electrical safety, insulation, thermal behavior, or production use.

The project is being developed in feature branches. The initial implementation targets discontinuous conduction mode (DCM) and supports multiple secondary windings and isolated output groups.
